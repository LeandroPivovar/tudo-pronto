# Tudo Pronto Serviços — site institucional

Site one-page da **Tudo Pronto Serviços**: reformas, construções e pequenos reparos em Pedra de Guaratiba, Rio de Janeiro.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, depoimentos, mapa, FAQ)
styles.css   # estilos (preto e dourado)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # marca provisória (logo.svg) e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.
